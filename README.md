## 住宅IP、原生IP、机房IP，风控看到的是三种东西

平台判断一个 IP 干不干净，看的是它在 IP 数据库里挂在哪类主体名下。

机房 IP 来自 IDC 数据中心，归属信息里写的是 Hosting、VPS、Cloud 这类标签。绝大多数低价 VPS 和共享代理出口都在这条线上，也是风控系统打分最高的一类。

原生 IP 指 IP 注册地和机房物理位置一致。它比广播到别处的机房 IP 干净，但本质还是数据中心出身，在数据库里的主体类型没有变。

住宅 IP 的归属是真实的家庭宽带运营商，比如美国的 NTT、GTT、AT&T。数据库把这类 IP 识别成普通居民用户，风控评级最低。

三者在实际业务里的差别很直接。用机房 IP 登录 ChatGPT，常见的是刚输完账号就跳“Access denied”，或者反复过 Cloudflare 人机验证，验证做完还是进不去。做 TikTok，账号刚注册就限流。绑 Stripe、Adyen 这类支付网关，交易被标成可疑。同一套浏览器、同一个账号，换成住宅 IP 之后这些提示会明显减少。

原生 IP 和住宅 IP 常被混着说，这是两个不同的东西。原生只说明“IP 注册地和机房对得上”，不说明它归属于家庭宽带。买之前把这两个概念分开看，能避开一批挂着“原生”名头卖机房段的套餐。

## 双ISP要两个维度都对，才叫双ISP住宅IP

“双ISP”指这个 IP 同时归属两个网络服务提供商，归属信息比单 ISP 更接近真实家庭网络。判断方法不复杂，看两个检测维度：

- **Company 类型**显示为 ISP，说明 IP 归属于网络服务提供商，而不是数据中心。
- **ASN 类型**也显示为 ISP。

两个维度都满足，才算完整的双ISP住宅IP。只满足一个，有可能是广播段伪装出来的“家宽”。

具体怎么验：

1. 用 ipinfo 查这个 IP 的 ASN 和 Company 两个字段，分别看类型。
2. 换 Scamalytics、IPQS 再查一遍 fraud score，单一工具的结果容易被针对优化。
3. 查 IP 注册信息和路由轨迹，真住宅 IP 的归属链路能对应到当地运营商的宽带网络。
4. 最后在真实业务环境里跑一遍，假住宅 IP 在风控严格的平台上很快会暴露。

这四步做完再正式部署业务，比事后找客服扯皮省事。到手就验，有问题在退款窗口内提。

## 按场景选，不按“性价比”选

**只给 ChatGPT、Claude 个人用。** 带宽 30–100Mbps 足够，流量 1TB 级别绰绰有余，账号类业务月消耗很少超过 500GB。这个场景的重点是 IP 干净，不是带宽大。买最便宜的一档，先月付，验完 IP 属性再考虑续长期。

**TikTok 养号。** 需要双ISP住宅IP 加独立 IP，一个号一个 IP。设备指纹、行为模式、发布频率同样影响风控结果，住宅 IP 只解决“IP 这一项不被扣分”。WePC 的西班牙马德里节点在这个场景里对口西语区账号，公开资料把 TikTok 养号直播列进了用途。

**TikTok 直播、素材上传。** 带宽要 100Mbps 以上，或者直接选不限流量。上行带宽比下行更关键，很多套餐标的是带宽上限，实际上行要单独问。Windows 支持也要提前确认，直播工具和自动化脚本大多跑在 Windows 上。

**跨境电商多账号。** 看两件事：能加几个独立 IP、支不支持 Windows 多开。莱卡云最多可加 5 个独立 IP，这类设计对多店铺运营更实用。

**欧洲、西语区业务。** WePC 的西班牙马德里双ISP 是现有资料里最对口的节点。德国住宅线可以作参照，但大陆访问要中转：电信走 GTT 出法兰克福绕荷兰，延迟 220–260ms；联通 200–237ms；移动 190–215ms。面向大陆用户的话，在香港或日本节点做中转再回源，体验会好一些。

## 常见问题

**住宅IP和双ISP是一回事吗？**
不是。住宅IP 指 IP 归属于家庭宽带运营商；双ISP 指 IP 同时归属两个 ISP。两者可以叠加，叠加后归属信息更接近真实家庭网络。买的时候两个属性都要看。

**AUD$8.90 是 WePC 所有套餐的价格吗？**
不是。这是公开资料对住宅IP产品线起价的描述。官网目前能直接看到价格的套餐里，Web/Email/Windows VPS 从 AUD$9.90/月起，香港 VPS 从 AUD$16.90/月起。AUD$8.90 对应哪个节点、什么配置，官网页面上没有核实到，进站后按地区筛选确认。

**买了 VPS 就能直接用 ChatGPT 吗？**
不能。VPS 只提供一个 IP，还要在上面搭代理服务，本地客户端连上去，流量才会走这条线。搭代理的工具有 Xray、v2ray、3X-UI 这类，装完建议开 BBR。

**1TB 流量够不够？**
账号运营类业务月消耗很少超过 500GB，1TB 够用。跑直播、大文件传输、视频搬运才需要往上加，这种场景直接看不限流量档。

**月付还是年付？**
先月付。住宅 IP 资源按批次分配，不同批次质量有差异，第一台验完 IP 属性和线路稳定性，再决定要不要转年付。

**被风控了换个 IP 有用吗？**
看风控触发的原因。IP 属性是其中一项，设备指纹、浏览器环境、操作行为、内容本身都会影响结果。只换 IP 不改其他环境，问题可能还在。
